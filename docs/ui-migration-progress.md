- 文章保留原标题锚点、公开状态检查、缓存、canonical、Open Graph、Article JSON-LD 与真实评论区域。
- Cherry Studio App 只说明移动端布局与核心功能实现，没有添加未经确认的成果或个人职责。
- 动效在组件卸载时清理；减少动态效果偏好可在运行中切换，文章正文保持稳定。
- 预览页面继续 noindex/nofollow，并排除站点地图。

## 环境限制与后续验证

- 搜索服务在本机返回 Algolia `Unreachable hosts`。已验证失败提示显示、关键词保留、重试入口可操作；检索成功与结果跳转需要服务恢复后复验。搜索客户端、索引和密钥配置未变。
- 友链查询在本机出现 Neon 数据库连接失败。保留真实查询，新增错误边界与重新加载入口；未用假数据代替真实友链。新版友链列表、友链信息复制与申请表单的完整运行验收尚待数据库恢复。

- 验证基于本地开发环境。未运行包含内容同步、搜索上传和外部索引提交的发布脚本，未建立生产性能基线。
- 登录与后台专项视觉改造仍属于后续阶段。
